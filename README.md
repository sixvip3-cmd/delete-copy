# delete — мессенджер

Мессенджер в стиле референсов: тёмная тема, синие пузыри сообщений, «стеклянный» таб-бар
«Лента / Чаты / Профиль» с круглой кнопкой «+».

## Возможности

- **Мессенджер** — личные чаты в реальном времени (WebSocket): ответы с цитатой (свайп влево,
  двойной клик или долгое нажатие), редактирование, удаление, копирование, «печатает…»,
  онлайн-статус, прочтения, непрочитанные, большие эмодзи, фото и видео, чат «Избранное».
- **Голосовые сообщения** — зажмите микрофон: отпустите, чтобы отправить; влево — отмена;
  вверх или короткий тап — запись «без рук». Волна громкости, перемотка по волне,
  скорость 1x / 1.5x / 2x, подряд идущие голосовые проигрываются автоматически.
- **Лента** — публикации с текстом, фото и видео (галерея до 10 файлов), лайки
  (в том числе двойным тапом), закладки, фильтры «Все / Подписки / Сохранённые».
- **Истории** — фото, видео или текст на градиенте, живут 24 часа. Полосы прогресса, тапы
  влево/вправо, удержание — пауза, ответ на историю приходит в чат, счётчик просмотров.
- **Профиль** — аватар с кольцом истории, имя с бейджем верификации, @юзернейм, описание,
  подписчики, кнопки «Подписаться/Отписаться» и «Написать», публикации, редактирование.
- Онбординг-карусель («Просто напиши», «Будь в теме», «Будь собой», «Всегда рядом»),
  регистрация и вход, поиск людей и чатов.

## Запуск

```bash
npm install
npm start          # http://localhost:3000
```

Кнопка **«Посмотреть демо»** входит в аккаунт `demo` / `demo` с готовыми переписками.
Демо-пользователи (delete, аринка, xdaszx, Moderator…) — боты: они отвечают на сообщения.

Данные хранятся в `data/db.json`, загруженные файлы — в `data/media/`. Чтобы сбросить всё
к исходному состоянию, удалите папку `data`.

Запись голосовых требует доступа к микрофону. Браузеры дают его только на `localhost` или по HTTPS.

## Стек

Node.js, Express, ws. Фронтенд — на чистом JS (ES-модули) без сборки.
